# annotools

`annotools` — небольшой утилитарный пакет для работы с `typing.Annotated`, валидацией аргументов и реестрами функций без привязки к конкретному UI‑фреймворку

## Возможности

- Простые валидаторы для целых чисел: `MinValue`, `MaxValue` с выбрасыванием `ValidationError`
- Универсальная функция `extract_validators` для извлечения метаданных из `Annotated`
- `build_kwargs_from_annotations` — построение `**kwargs` на основе аннотаций и колбэков, которые решают, как спрашивать значения у пользователя
- Лёгкий реестр функций `Register`, удобный для CLI‑утилит и плагин‑подхода

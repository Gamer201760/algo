# annotools

`annotools` — небольшой утилитарный пакет для работы с `typing.Annotated`, валидацией аргументов и добавление метаданных без привязки к конкретному UI‑фреймворку.

Пакет помогает описывать ограничения и метаданные прямо в аннотациях типов, а затем удобно извлекать их во время выполнения.

---

## Возможности

- Работа с `typing.Annotated`:
  - Нормализация базового типа (через `get_origin`) и аргументов (через `get_args`).
  - Извлечение метаданных из аннотаций.
- Итерация по параметрам функций:
  - `iter_parameters(func)` генератор, который возвращает информацию о параметрах с учётом `Annotated`.
  - Возвращает структуру `ParamInfo` с полями: `name`, `base_type`, `args`, `metadata`, `default`.
- Простые валидаторы для строк и чисел:
  - `TypeValidator` проверка и приведение значения к нужному типу, выбрасывает `ValidationError` при ошибке.
  - `MinValue` и `MaxValue` — ограничения на целочисленные значения.
  - `StrLen` ограничение максимальной длины строки.
- Работа с метаданными:
  - `MetaData` протокол для пользовательских метаданных.
  - `Message` удобный контейнер для человекочитаемых сообщений/лейблов.
  - `extract_validators(meta)` извлечение всех валидаторов из списка метаданных.
  - `extract_messages(meta)` извлечение всех сообщений из списка метаданных.

---

## Базовая идея

Основная идея описывать требования к параметрам прямо в аннотациях типов через `Annotated`, а затем на этапе выполнения:

1. Пройтись по параметрам функции через `iter_parameters`.
2. Извлечь из `metadata` валидаторы (`Validator`) и сообщения (`Message`).
3. Выполнить валидацию входных данных и, при необходимости, отобразить пользователю соответствующие сообщения.
---

## Пример

```
n: Annotated[
    int,
    NumValidator(),
    TypeValidator(int),
    MinValue(0),
    MaxValue(1558),
]
```

## Свои метаданные и валидаторы

`annotools` не ограничивается встроенными классами. Можно описывать свои метаданные, реализуя протоколы `MetaData`, `Validator` или используя `Message` как есть.

```
from dataclasses import dataclass

from annotools import ValidationError


@dataclass(frozen=True)
class NonEmpty:
    def validate(self, value: str) -> None:
        if not value.strip():
            raise ValidationError("Значение не должно быть пустым")
```

Дальше эти классы можно использовать внутри `Annotated[...]` и извлекать через уже готовые функции (`extract_validators`, `extract_messages` или собственные фильтры по `isinstance`).
